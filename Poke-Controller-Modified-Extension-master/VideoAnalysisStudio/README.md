# PokeCon Video Analysis Studio

PokeConから独立して動く、保存動画の解析・切り抜きレビューGUIです。

## 起動

PokeConの **Others → 動画解析GUI** から起動します。このボタンを既に起動中のPokeConへ反映するには、本体の通常の再起動が必要です。GUI単体は本体を再起動せず、プロジェクト直下で次のように起動できます。

```powershell
.venv314\Scripts\pythonw.exe -B VideoAnalysisStudio.pyw
```

`--project <解析プロジェクト.json>`、`--folder <フォルダ>`（複数指定可）、`--settings <PokeConのsettings.ini>`も使用できます。PokeConから起動するとそのプロファイルの設定ファイルを引き継ぎます。カメラ・コントローラーには接続しません。

## 解析と表示範囲

1. 「解析・連続再生」で対象フォルダを繰り返し追加します。配下のMP4/MKV/AVI/MOV/M4V/WebM/MTS/M2TS/WMVを再帰検索し、重なるフォルダは重複走査しません。解析ツール自身の出力・ライブラリは除外します。
2. 初期条件はZAの非戦闘フィールドHARD CHECKです。現行Commandsソースから画像・閾値・ROIを読み、フィールド表示、手持ちアイコン、戦闘表示の除外を同一保存フレームで判定します。ゲーム実行時のfresh frame連続確認とは別のオフライン条件です。
3. 「切り抜き条件」で画像、AND/OR/除外、閾値、グレースケール、検索ROI、テンプレート内ROIを編集します。Commandsソースの登録画像やDevStudio画像ライブラリもコピーできます。ソースを実行・変更しません。成立／解除の前後、一致／不一致区間の抽出が選べます。
   「PokeConの切り抜き条件をコピー」は、指定したPokeCon設定の条件クリップから画像・AND/OR・1〜2段階の順序・継続秒・段階間制限・再検出間隔・前後秒数を取り込みます。順序と継続の判定には本体側の`EventClips.EventSequence`を共用します。解析側で変更しても本体設定は書き換えません。順序条件は「成立の前後」で使用し、各段階グループの継続秒と、最上位の制限秒・再検出間隔を編集できます。
4. 「条件を適用」して「選択条件で解析開始」を押します。初期解析間隔は0.5秒、2標本の連続確認です。間隔0は全フレーム走査です。間引きは標本間の短い表示を見落とします。時刻は動画のフレーム番号とFPSに基づくため、ゲーム用の固定FPS録画を想定しています。
5. 前後秒数の変更は、元動画に対する表示範囲だけを変えます。「4秒」「10秒へ戻す」、個別調整、Undo/Redoに対応し、再切り出し・再解析はしません。前後とも0秒の点イベントは最低1フレームを表示します。

元動画、検出時刻、条件、条件画像のハッシュ、元動画のサイズ・更新時刻、走査の成否をプロジェクトに保存します。失敗・中止を全件完了として扱わず、完了済み動画の結果を保持します。条件の編集途中も下書きとして保存されます。別ウィンドウで変更されたプロジェクトは上書きせず別保存を案内します。

次回の走査では、動画・画像・条件が変わっていない完了結果を再利用し、新しい動画を追加解析します。「変更なしの動画も再解析」をONにすると全件を調べ直します。

## 再生、類似、蓄積

「選択を再生」「一覧を連続再生」「類似内を全再生」が使えます。1倍速と2〜10倍速に対応し、再生中も切り替えられます。プレビューは無音・表示間引きで、書き出したMP4には元の音声を保持します。別録画からの解析結果も一つの一覧でつながります。

類似分類は各表示区間の5地点から画像の形・色と長さを比較する候補判定です。完全な重複判定や意味上の同一性は保証しません。グループの代表との比較で分類し、連鎖的に似ているだけの候補を統合しません。閾値を変更して再解析できます。表示範囲が変わると古い類似分類を使用しません。

「類似順」「代表のみ」で絞っても、グループ内の元候補を全再生できます。「選択を代表に」「別のユニーク候補に分ける」「確認済みにする」で見比べた結果を残せます。類似の再解析はグループの手動編集を再構成するため、確定した動画は蓄積してください。

「ユニーク蓄積」で選択候補を専用ライブラリに追加すると、MP4と出典を保存します。元動画を移動した後も再生できます。同じ元動画・同じ表示範囲の重複登録は防ぎます。「蓄積内も類似を確認」「解析候補と蓄積を比較」で追加分を確認できます。自動分類による動画の削除はありません。

## 書き出しとYouTube

対象はフォルダ配下の全動画、解析一覧、解析の選択から選べます。フォルダ全動画はパス順、解析結果は現在の一覧順です。マージのON/OFF、分割の分数（0=分割なし）を設定し、「対象を確認」で一覧を見てから書き出せます。出力は毎回別フォルダとmanifestに保存し、入力を上書きしません。映像サイズ・FPSが異なる場合、書き出しは先頭動画の形式へ統一します。音声がない動画には無音を補います。倍速プレビュー設定は書き出し速度へ適用しません。

YouTubeはPokeConのチャンネル認証と永続アップロードキューを共用します。チャンネルの追加認証、分割（共有キューでは10分〜11時間）、限定公開、再開に対応します。0分を指定してもYouTubeの共有キューでは11時間ごとの保護分割が適用されます。アップロード対象の一覧・件数・チャンネルを確認後に登録します。元動画の削除設定は常に無効です。キュー登録はアップロード完了を意味せず、「キューを更新」で状態を確認します。

新しく作ったファイルはローカルで視聴・検証できます。YouTubeへの実送信は、GUIでユーザーが選んだ対象について実行します。

## 開発確認

```powershell
.venv314\Scripts\python.exe -B -m unittest tests.test_video_analysis_studio tests.test_video_analysis_gui
.venv314\Scripts\python.exe -B -m unittest tests.test_automation_features
```

専用テストは実ファイルの復号・検出時刻、可逆な前後範囲、類似分類、Tkの再生と下書き、MP4の結合・分割・音声復号、永続ライブラリ、既存キュー登録を検証します。カメラ、ゲーム入力、実際のOAuth・YouTube送信は行いません。PokeConのFPS制御はこのツールの変更範囲に含みません。
