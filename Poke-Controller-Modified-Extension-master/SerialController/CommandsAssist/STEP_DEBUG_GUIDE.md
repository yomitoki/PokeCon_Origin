# Stepデバッグアシスト 使い方

この機能は、シナリオの問題箇所まで何度も戻る作業を減らすための調整用機能です。

## いつもの操作順

1. CommandsAssist の「かんたんStepデバッグ」を開きます。
2. 「① 停止地点を追加」で Commands、状態変数、Step名を選びます。
3. 「この設定を有効」にして、通常どおり Commands を Start します。
4. 指定Stepの関数に入る直前で自動停止します。
5. 一覧の上から「③ 選んだ1個を実行」で動作を確認します。
6. 修正したい処理は「選んだ処理を修正」または「PC操作記録で置換」を使います。
7. 調整中の置換は別設定に保存され、元のPythonソースは書き換えません。
8. 問題なければ「④ 次Stepへ進む」を押します。

## ボタンの違い

- **1個を実行**: 選んだ行だけを試します。
- **ここまで実行**: 未実行の先頭から選択行まで順番に試します。
- **処理を修正**: 調整用コードを保存し、以後の試験で使います。
- **PC操作記録で置換**: 登録済みのコントローラー記録をその行の代わりに再生します。
- **今からPC操作を記録**: 停止中のままPCゲームパッドで代わりの操作を行い、その記録を選択行の一時置換として保存します。
- **次Stepへ進む**: 元関数は実行せず、選んだ次状態を返します。
- **元関数を実行**: 手動調整を終え、元の関数を最初から通常実行します。

## 注意

- IF条件内の処理は、条件名を一覧に表示します。手動実行時は、現在のゲーム状態に合う処理だけを選びます。
- ローカル変数に依存する処理は単独実行できない場合があります。その場合は、必要な値を `self.xxx` または数値に置き換えて保存します。
- 元のPythonソースへの本反映はDevStudioの関数置換から明示的に行います。
