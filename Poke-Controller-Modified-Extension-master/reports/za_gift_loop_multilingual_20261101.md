# ZA おくりものループ: 捕獲処理の修正と他言語対応で難しかった点

作業日: 2026-11-01。実機（Switch 初代・本体の言語は日本語・ホワイトテーマ）で確認した。コミットはしていない。

## 結論

- コフキムシの捕獲は、捕獲するまでの時間が 148〜190 秒から 6〜10 秒になった。原因は、投げる直前の名前確認でロックを外していたこと、ロックをかけ直した直後に「マーク無し」と判定して攻撃していたこと。
- 名前入力は全10言語に対応した。英字・アクセント・ハングル・記号・空白・大文字・中国語の変換（簡体字ピンイン・繁体字注音）を、実機の PROFILE 画面で確認した（17件）。
- 補完モードの英語のおくりものループは、ストーリーを最後（Z_35）まで通し、ふしぎなおくりものの入口まで進んだ。止まった所はすべて直した（6章）。おくりもの以降は、ユーザーが撮った英語の画面で確かめた。通しの実行は別PCで行う。
- 補完モードは PokeCon 本体ではなく Commands 側（ZA_story・LocalFunction/ZA・Pokemon_Template/ZA・Template）に移した（7章）。標準の PokeCon でも動く。
- 補完モードでは、文字のある判定をマーク・アイコン（A の字、♂/♀、▼、ZL/ZR、≡・通信・プレゼント箱、鉛筆、ボックス）で置き換えた。置き換えるたびに、日本語の保存フレームで元の判定と結果が同じことを確かめた。
- 日本語のおくりものループは1周を最後まで通した（コフキムシ 10 秒、HOME 輸送、削除後は開始時と同じ7人）。

## 1. コフキムシ: ロックオンしても攻撃・捕獲しない

録画（steps.jsonl と動画）を読み直して分かったこと:

- マーク4つ（捕獲しやすい状態）と名前（一致度 0.95）が出ているのに、投げる前の名前確認でロックを外して 0.05 秒後に押し直していた。間隔が短くロックが掛からず、薄れていく名前を見て確認に失敗していた。そのたびにロックを外すため、26 秒間投げられなかった。
- ロックをかけ直した直後は、前のロックの HP バーだけが残り、マークは遅れて出る。HP バーだけを見て「マーク無し」と判定し、攻撃していた。その攻撃で、HP 満タンでもマーク4つのコフキムシを倒していた。次のコフキムシが出るまで2分以上待つことになっていた（「2体目以降に時間がかかる」の原因）。

直した内容（`ZA_get_pokemon`・`_1_story_capture_lockon_attack`・`_za_capture_wait_view`）:

- 今のロックのまま名前を2回確かめて、そのまま投げる。名前が見えない時だけ 0.2 秒あけて掛け直し、表示が出るまで最大 1.2 秒待つ。確かめられなくてもロックは外さない（別の種族と確認できた時だけ外す）。
- ZL を押した直後は、HP バーが見えただけでは返さず、マークが出るのを待つ。直近 10 秒以内にマーク4つが見えた相手には攻撃しない。

## 2. ビードル

- 移動を 0.5 秒延ばした（155 度・3.3 秒）。延ばした後の2周は、1周目が1球で捕獲、2周目が5回目の到着で捕獲。
- 失敗の内訳（2周目）: 別の種族（名前で判定）にロックし続けた、HP バーの相手がいない、投げたが植え込みの陰で捕まらない。出現位置によって成否が変わる。
- 追加した処理（ユーザー指定）:
  - 投げた後に捕まっていなければロックし直し、見えれば投げ直す（最大3球）。
  - ロックできない時は、左スティックで少し右へ向きを変えてロックし直す（最大3回）。
  - 右スティックで視点だけを回すと、ZL を押した時に視点がキャラの向きへ戻るため、キャラの向きごと変えている。
- ビードルは日本語の名前画像で他の種族と見分けるため、日本語以外（補完モード・他言語のループ）ではメリープにした。

## 3. ワイルドゾーンの出口（「A でる」で早めに出る）

- ビードル後に出口へ向かう5秒の移動を 0.5 秒ずつに分け、「A でる」が出たらその場で出る。Z_21 の壁沿いの移動の前にも確かめる。
- 実機で約3秒でゲートに着く回と、柱の横に着いて「A でる」が出ない回があった。後者は元の Z_21 の処理で出ている（誤って押すことはなかった）。
- 補完モードは「A」の字だけの判定になるため、別の A 表示（拾う など）で押すことがある。ユーザー確認のとおり、その時は Z_23 の再起動（120 秒）でやり直す。

## 4. 別PCでのエラー（getmerker4.png が見つからない）

- `ZA_capture_target_view` が、ZA_story.py から4階層上の Template を決め打ちしていた。開発環境（`PythonCommands/ZA/ZA_story/`）と配布先（`PythonCommands/ZA_story/`）で階層が1つ違うため、配布先では別の場所を探していた。ビードルの画像保存（Captures）も同じだった。
- PokeCon の `get_filespec`（Template・Captures）を使うように直し、`__file__` から `..` をたどる書き方が無いことをテストで確かめる。
- Reload で重なるコマンド名の後ろの「(ZA/ZA_story/ZA_story)」も、置き場所によらず1つに戻すようにした。

## 5. 他言語の名前入力で難しかった点

### 言語選択

- 並びは直前に選んだ言語で変わる。直前の言語が左上に来て、残りは決まった順に並ぶ。位置ではなくボタンの文字（言語名の画像10枚）で探す。
- 直前の言語はセーブデータに残る。ZA を起動して言語を選んだだけでも、セーブデータ消去の一覧に行が増える。番号方式は「今回増えた1行だけを消す」ため、手で試した後は先にその行を消さないとループが削除の段階で止まる（実際に1回止まった。誤削除はしない）。
- 見出しも言語で変わる（LOOKS / APPEARANCE / APARIENCIA / AUSSEHEN / ASPETTO、PROFILE / CONFIRM CHOICES / PROFILO）。見た目は顔画像8枚、PROFILE は「言語」「名前」の白い札で判定する。

### キーボード（日本語以外は Switch 本体のキーボード）

- 配列: 英・西・仏・独・伊は同じ QWERTY（12文字）、韓国語は2ボル式（6文字）、中国語は拼音／注音（6文字）。操作説明は本体の言語。
- 前回使ったモードで開く（例: 前回 符號 で終えると 符號 で開く）。モードは下線の色で毎回確かめる。
- 大文字は左スティック押し込み。押すたびに「次の1文字だけ大文字 → 大文字固定 → 解除」と変わる。⇧ キーの塗りつぶしで状態を確かめる。大文字固定の印（青い点）がカーソル枠の色判定に混ざったため、色の固まりのうち一番大きいものを枠とした。
- 空の時の B はキーボードを閉じる。韓国語は入力中の文字があると OK の位置が「確定」になり、1回目の + で確定、2回目で決まる。
- まとめて押すと入力の取りこぼしが起きる（手動の確認で何度も起きた）。実装ではカーソル位置を1入力ごとに画面で確かめる。

### 中国語の変換

- 読みを打つと上の列に候補が出る。R で先頭へ入り、R/L で1つずつ動き、A で決める。決めた後もカーソルは候補の列に残る。注音の1声は記号なしで候補が出る。
- 変換中の読みも文字数に数える（例: 晓 ＋ ming で 5/6）。確定済みの字数と読みの長さの合計が上限を超える名前は、開始前に止める。
- 候補の字は、Windows のフォント（Microsoft YaHei / JhengHei）で描いた字と照合する。Switch とはフォントが違うため、偏だけ違う字（晓・哓）は区別しきれず、止める扱いにした。
- 実機で1回、「红」を見つけられず止まった。カーソル枠の中の字は細い線が1行・1列欠けて位置がずれ、一致度が 0.73 から 0.47 に落ちていた。±4 画素のずれと ±10% の大きさの違いを許すようにした（今は 0.86）。しきい値は一致度 0.65・2位との差 0.10。
- 名前とは別に「変換の読み」の欄を設けた。サンプル: 小明 `xiao ming` / 小红 `xiao hong` / 小明 `ㄒㄧㄠˇ ㄇㄧㄥˊ` / 小美 `ㄒㄧㄠˇ ㄇㄟˇ`。

### 1回目（13:51 開始、Alex・男性）: BAG_CHASE_END で止まり、リセットも失敗

- 列車を降りてからバッグを追う所までは進んだ。最初のポケモン選びの前（`1_STORY_BAG_CHASE_END`）で、B 連打のまま約10分「A 話しかける」を待ち、時間切れでゲームを再起動した。
- 原因1（A 表示）: 「A＋文字」の表示（話しかける・でる・入る・のぼる・調べる など）は、今朝の「Switch版おくりもの対応」から `ActionPromptCheck`（日本語の単語画像の一覧）で判定していた。補完モードで A の字だけに置き換える処理は、元の画像判定（`detect_image`）の中にしかない。このため補完モードでも日本語の単語を探し続けていた。ユーザーが 10/30 に足した「明るい石畳の前の A 話しかける」（talk_light_ja、BAG_CHASE_END 用）も日本語の単語画像なので、英語では一致しない。
- 原因2（リセット）: タイトルの判定画像が日本語版の「PRESS Ⓐ BUTTON」だった。英語版は「PRESS Ⓐ」だけ（右下に Downloadable Content Available）で、一致度 0.40。ゲーム画面待ちが 180 秒で止まった。

直した内容:

- 補完モードでは、`ActionPromptCheck` が日本語の単語画像を使わず、登録済みの画像判定（補完モードで A の字だけになる）に任せる。調査の A は `ZA_STORY_COMMON_ZA_RESEARCH_A`、単語だけの参照（`ZA_ACTION_PROMPT_*`）は汎用の A（`POKEMON_ZA_OTHER_A_MARKER`）で確かめる。日本語（補完モード以外）は今までどおり。
- タイトルは、補完モードの時だけ A の丸（`za_title_a_glyph.png` / `za_title_a_glyph_end.png`、元の2枚から切り出し）でも判定する。英語のタイトルで 0.970、日本語の明るいタイトルで 1.000、ほかの保存フレーム90枚では 0.75 未満。フィールドが見えている間は使わない（A 表示の取り違えを防ぐ）。
